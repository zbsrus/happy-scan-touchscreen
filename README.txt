HAPPY SCAN

Системные требования
- Windows 10 или Windows 11.
- Microsoft Edge или Google Chrome.
- Разрешение экрана 1920×1080, горизонтальная ориентация.
- Рекомендуемый масштаб Windows: 100%.

Обычный запуск
1. Распакуйте архив полностью в отдельную папку на локальном диске.
2. Откройте файл start.bat двойным нажатием.
3. Игра запустится в полноэкранном режиме.
4. Для выхода из полноэкранного режима нажмите Esc или F11.

Запуск на тач-панели
1. Перед мероприятием проверьте работу игры на конкретной панели.
2. Для запуска без вкладок и адресной строки используйте start-kiosk.bat.
3. Для выхода из киоск-режима нажмите Alt+F4.

Если автоматический запуск не сработал, откройте index.html в Microsoft Edge или Google Chrome.

Важно: не перемещайте и не переименовывайте отдельные файлы внутри папки игры.
